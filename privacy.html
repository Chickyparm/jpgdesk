Privacy

The files stay
where you dropped them.

Conversion and compression run in JavaScript on this device. Images are not posted to a JpgDesk server to build the PDF.

The free-quota counter lives in localStorage on this browser. That is a number, not your photos.

Hosting, analytics, and payment (when Stripe is connected) can see that a page was loaded. They do not see the image bytes unless you later add an upload path. Do not add one.

If you connect checkout, Stripe will hold billing identity. Keep that separate from the file pipeline.
